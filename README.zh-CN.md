一帘月夜紫藤，用 ASCII 字符画在 canvas 上。给它一张照片，照片就会活过来：花串随风轻摆，鼠标经过时被推开又荡回；落花从花朵上飘下，在地面慢慢积起；鼠标经过的地方留下一缕暗香，好几秒才散。不给照片时，它会自己画一帘紫藤插画。零依赖。

![预览](docs/preview.png)

```sh
npm install && npm run dev
```

```ts
import { WisteriaEngine } from "./src";

new WisteriaEngine(canvas, { image: "/wisteria.jpg" }); // canvas 需要设置等宽字体（font-family）
```

**选什么照片**：效果最好的是紫藤从画面顶部垂下、背景较暗、有几串清晰对焦的照片。照片会按铺满（cover）的方式适配画布。不传 `image` 时使用内置插画；照片加载失败时也会自动退回插画。

## 设计

| | |
|---|---|
| **浪漫** | 一切都慢：花串以约 5 秒的节奏摆动，花瓣像散步一样徐徐飘落。 |
| **思念** | 鼠标留下一缕暗香，像焚香的烟一样上浮、打旋，几秒内由 `*` 冷却成 `.`。落花慢慢堆积，约一分钟才淡去。偶尔有一片花瓣在半空停住片刻，像在回望。 |
| **高贵 · 冷静** | 近乎黑色的底上一片蓝紫，用的是照片本身的颜色，没有别的颜色与花争色。 |

默认画面是一张夜间紫藤照片（[`public/wisteria.jpg`](public/wisteria.jpg)）：两串清晰的主角花串浸在光里，其余渐次虚化成柔和的散景，左下角一道虚焦的藤蔓做前景框。内置插画也按同样的构图来画。

### 会发生什么

- **开场**（约 16 秒）：照片从上往下逐列显现，由暗渐亮，像花串慢慢长出来。点击可跳过。（没有照片时，改为插画的藤蔓生长、花苞开放。）

  ![生长](docs/blooming.png)

- **暗香**：鼠标是一阵风，掠过时把花串推开；也是一盏小灯，靠近处的花会亮起。它身后每隔一小段就留下一粒香气微粒：微粒带着一点鼠标的速度，然后慢下来、上浮、打旋，两侧还散出更淡的烟丝。微粒飘过的花会被短暂映亮。
- **涟漪**：点击会发出一圈 ASCII 字符画成的涟漪，约 3 秒缓缓扩散，隔半拍跟着一圈更淡的虚线回声。涟漪扫到哪串花，哪串才摆动、落瓣；扫过地面时会惊起积花。整个点击像一道波，从近到远传遍画面。

  ![涟漪](docs/interaction.png)
系统开启"减少动态效果"（`prefers-reduced-motion`）时，只显示一帧盛开的静止画面。canvas 滚出屏幕时停止渲染。

## 参数

```ts
new WisteriaEngine(canvas, {
  image: "/wisteria.jpg",   // 要让它活起来的照片；不传则使用插画
  intro: true,              // 开场（照片逐渐显现，或插画生长）；false 时直接盛开
  density: 1,               // 花串密度（相对值）
  wind: 1,                  // 风力（相对值）
  palette: { skyTop: [12, 9, 30] }, // 覆盖月光配色中的任意颜色
});
```

演示页 URL 参数：`?image=0`（插画）、`?image=/other.jpg`、`?intro=0`。演示页使用 `public/wisteria.jpg` 这张照片。

React：

```tsx
import { AsciiWisteria } from "./src/react";

<AsciiWisteria className="hero" options={{ intro: false }} />;
```

## 实现

核心思路：**先把紫藤画成一张真正的插画，再把这张图转成字符。** 图像紫藤，ASCII 就像紫藤。只按亮度挑字符，结果只是一片紫色噪点；真正让人认出形状的，是几个大的剪影、剪影之间大片的黑、花瓣内部统一的表面，以及顺着花瓣走的轮廓。

有些题材很难画得逼真：我们手绘的小花总是像一串葡萄。所以引擎也可以直接用照片做画面来源。无论哪种来源，每一帧都是把一张图转成字符。

和启发了本项目的 [ascii-sharks](https://github.com/stackedlol/ascii-sharks) 一样分层：

- **`world.ts`：以像素为单位的物理。**
  - 每串花是一条 14 个节点的 verlet 链，挂在枝上，加了一点抗弯，让花串整体摆动。
  - 小花分别朝左、朝右挂，在密集的上部还有朝向观者的；顶部大而层叠，往下成对变小，最后以花苞收尾。
  - 尺寸都按屏幕比例设定，任何尺寸下构图都一致：两串大的主角花串，几串避开主角的中景花串，后排虚化的花串，顶部一排羽状复叶。
  - 风是两道缓慢的起伏，加上约 40 秒一轮的阵风；鼠标的速度推动附近的节点；涟漪只有扩散的边缘会推，所以摆动一路向外传开。
- **`photograph.ts`：画面来自照片。**
  - 照片按铺满方式画进采样画布（每格 5 × 8 个采样点），按 40 根钟摆列切成小块绘制。
  - 每列是一个周期约 5 秒的阻尼钟摆，越往下摆幅越大，所以垂下的花串整串摆动，顶部的叶子几乎不动。风、鼠标和涟漪的边缘都会推动这些钟摆。
  - 照片里亮的像素就是落花的来源。
  - 开场时照片从上往下逐列显现。
- **`illustrator.ts`：画面来自插画（没有照片时）。** 每一帧用矢量形状画在一张离屏 canvas 上，每个字符格对应 4 × 6 个采样点。
  - 每朵小花由两部分组成：一片向上后方翻起的宽大旗瓣，和一片挂在短梗上、向外下垂的龙骨瓣。两者都从左上方受光，有一道月光亮边和一圈暗色描边。
  - 远处的花串画成柔和重叠的圆斑，转出来就是散景。
  - 叶子是带主脉的披针形。
- **`renderer.ts`：画面转字符。** 逐格读回采样点。
  - **照片**：每格选与格内明暗图案（相对于格内最亮的采样点）最吻合的字符，用照片自身的颜色按该亮度着色。约九成的格子是 `@`，所以先试 `@`（内部平坦的格子直接跳过匹配），其余候选就能提前停算。
  - 照片层按三帧轮换刷新（上半屏、下半屏、重绘），单帧不会承担全部开销；叠加层每帧都重画。
  - **插画**：做法如下。
  - **平坦的格子**按亮度从一组很短的符号 `.:;o%@` 里取字符，亮度先经过伽马曲线，让一片花瓣读成一个整面，明暗交给颜色。
  - **边缘格子**（部分覆盖、对比强）按形状匹配笔画字符（`/ \ | ( ) _ ' , ^ v`），轮廓顺着花瓣走。
  - **很暗的格子**只画一个柔和的点。
  - 字符颜色取被覆盖像素本身的颜色，整体等比提亮，高光不会发白，仍是紫色。
  - 月亮、星星、落花、香气微粒和涟漪直接以字符画在最上层。
